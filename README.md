Library-OOP (Library Management System)
	This is a Python-based Library Management System made using Object-Oriented Programming for our CSSDF01 course, finals term.

Features:
- Adding and searching library items(books, magazines, theses, etc.)
- Registering user as student and faculty members
- Borrowing and returning library items
- Calculating fines for overdue returns
- Renewing loans when they are not overdue
- Generating overdue loan reports
- Running tests programmed to check if features are functioning properly.

Requirements:
- Python

How to Run?
- Open a terminal inside the project folder(library-oop)
- Activate the virtual environment
- Run the program using: python main.py
